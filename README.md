# 练老师工具集 (LianLaoshi Tools)

一个功能强大的ComfyUI自定义节点集合，专为中文用户优化，提供音频处理、视频生成、图像处理、提示词优化等一站式AI创作工具。

## 🎯 功能特色

### 🎵 音频处理模块
- **智能音频转录** - 基于Whisper的精准语音识别，支持中文优化
- **音频分离** - 智能人声/背景音乐分离
- **音频选择** - 批量音频文件管理和选择
- **音频分割** - 按时间或标记点分割音频

### 🎬 视频处理模块  
- **视频合成** - 图片序列+音频合成高质量视频
- **视频转场** - 专业级视频转场效果
- **WAN动画嵌入** - 先进的视频动画生成技术，支持智能颜色匹配
- **MoCha循环嵌入** - 长视频循环编码，支持上下文窗口优化

### 🖼️ 图像处理模块
- **图像工具集** - 图像格式转换、尺寸调整、质量优化
- **智能反推** - AI图像内容分析和提示词反推
- **批量处理** - 支持图像批量处理和自动化工作流

### 📝 提示词优化
- **智能提示词** - 基于LLM的提示词生成和优化
- **随机提示词** - 创意灵感生成器
- **提示词配置** - 可自定义的提示词模板系统

## 🚀 快速开始

### 安装步骤

1. **克隆或下载** 本仓库到ComfyUI的`custom_nodes`目录
   ```
   cd ComfyUI/custom_nodes
   git clone [仓库地址] lianlaoshi_tools
   ```

2. **安装依赖** 
   ```
   cd lianlaoshi_tools
   pip install -r requirements.txt
   ```

3. **配置API密钥** (可选)
   - 复制`config/api_keys.json.example`为`config/api_keys.json`
   - 填入您的API密钥以启用高级功能

### 基本使用

每个模块都提供了直观的节点界面，您可以通过拖拽方式在ComfyUI中构建工作流：

- **音频工作流**: 音频转录 → 文本处理 → 语音合成
- **视频工作流**: 图像生成 → 序列处理 → 视频合成
- **批处理工作流**: 批量输入 → 自动化处理 → 结果输出

## ⚙️ 高级配置

### 音频转录优化
- 支持多种语言：`zh` (中文), `en` (英文), `ja` (日文), `ko` (韩文)等
- 中文环境推荐直接使用`zh`选项，比自动检测更准确
- 支持自定义提示词以提高转录准确性

### 视频处理优化
- **内存优化**: 启用瓦片编码降低显存占用
- **质量控制**: 可调节的颜色一致性和匹配算法
- **长视频支持**: 智能窗口分割和循环处理
- **颜色漂移修复**: 新增智能颜色匹配算法，支持adaptive/reinhard/mkl等多种方法，有效防止长视频颜色偏色问题

### 批处理配置
- 支持大规模批量处理
- 可自定义处理参数和输出格式
- 提供详细的处理日志和进度显示

## 💡 使用技巧

1. **音频处理**: 对于中文音频，建议直接选择`zh`语言选项以获得最佳转录效果
2. **视频生成**: 长视频建议使用MoCha循环节点，支持更高质量和更低内存占用
3. **颜色匹配**: WAN动画节点提供智能颜色匹配，可自动优化色彩一致性
4. **内存优化**: 处理高分辨率内容时，建议启用瓦片编码选项
5. **颜色偏色修复**: 长视频生成时出现颜色偏色，可调整`color_consistency_weight`参数(0.7-0.95)，数值越高颜色一致性越强

## 🔧 故障排除

### 常见问题
- **内存不足**: 启用瓦片编码或减少批处理大小
- **转录不准确**: 检查音频质量，使用适当的语言选项
- **视频生成失败**: 确认输入格式和参数设置
- **长视频颜色偏色**: 调整`colormatch`参数为`adaptive`，增加`color_consistency_weight`至0.9以上，或启用`auto_color_match`自动优化

### 性能优化
- 合理设置批处理大小以平衡速度和质量
- 使用适当的上下文窗口大小处理长视频
- 启用必要的缓存和优化选项
